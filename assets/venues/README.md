# Painted court environments

Original project assets generated using the built-in image_gen tool. No source artwork was copied from the reference games. Source PNGs are preserved at their generated resolution; the game aligns their baseline locations and overlays the live court and net. Retro Pixel uses a cached reduced-resolution treatment of the same environment.

## Shared generation prompt

Create a production game environment bitmap, wide landscape 16:10 composition, original Ghibli-inspired hand-painted anime background, gouache foliage, delicate architectural detail, warm natural light, soft painterly shadows, rich but restrained colors. Elevated fixed camera looking down the length of an EMPTY pickleball court, centered and symmetrical one-point perspective, no people, no UI, no writing, no logos. Layout on a virtual 960x600 frame: the playable court will be composited by the game over the quadrilateral with far corners (350,204),(610,204) and near corners (258,578),(702,578). Keep that central quadrilateral completely empty, flat muted teal asphalt with NO LINES and NO NET, no shadows on that area. Make everything outside it a continuous believable sports facility in matching perspective: level paved runoffs surrounding the court, side fencing and gates, benches, planted edges, realistic foreground pavement. All objects must remain outside the central trapezoid. Far baseline at about 34% image height, near baseline at96% height. Do not add a second court. Atmosphere should be an actual immersive place around the court, NOT a wallpaper panorama or vector shapes.
