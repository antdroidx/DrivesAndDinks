# DEV playtest scorecard

Test the current DEV source at https://antdroidx.github.io/DrivesAndDinks/dev/. Open https://antdroidx.github.io/DrivesAndDinks/dev/?test=performance to show the lightweight frame/render probe. The same metrics are available from the browser console with `window.__DRIVES_DINKS_PERFORMANCE__()`.

Use one downloaded report per match or practice session. Record the build shown in the header, device, browser, orientation, format, difficulty, archetype, seed when used, and any video or screenshot reference.
